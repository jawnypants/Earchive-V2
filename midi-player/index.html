About the Earchive

This project is an exploration into what the music we know might have sounded like if things had been every so slightly or vastly different.

Change a MIDI arrangement in the Recomposer, build playlists in the Librarian, or listen to and share broadcasts on RadioGraph.

Built with FluidSynth and Scala tuning files from the Huygens-Fokker Foundation.
